## 왜 만들었나

공공기관 게시판과 오래된 페이지에 불법도박 광고가 몰래 끼워지는 일이 반복되고 있습니다.
이런 광고는 사람 눈에는 보이지 않게 숨기고 검색엔진에만 노출하므로, 담당자가 화면을 둘러보는 것만으로는 찾기 어렵습니다.

## 무엇을 찾나

| 숨김 수법 | 예 |
|---|---|
| 닮은꼴 글자 | 라틴 문자 사이에 모양이 같은 키릴·그리스 문자를 섞음 (`cаsino`) |
| 자모 분해 | 한글을 자음·모음으로 풀어 씀 (`ㅂㅏㅋㅏㄹㅏ`) |
| 투명 텍스트 | 글자색을 투명하게 하거나 배경색과 같게 함 |
| 화면 밖 숨김 | 글자를 화면 바깥으로 밀어내거나 크기를 0으로 만듦 |

이 밖에 검색봇에게만 다른 내용을 보여 주는 **클로킹**(네이버·다음 기준), 몰래 만든 **기생 페이지**, 이미지 광고 배너, 불법 사이트로 가는 링크, 숨은 iframe도 찾습니다.

## 어떻게 다른가

- **실제 브라우저로 화면을 그려서 판정합니다.** 소스 코드만 훑지 않고, 사람이 보는 화면 그대로 숨김 여부를 확인합니다.
- **한국어 변형을 풉니다.** 자모 분해, 닮은꼴 글자, 초성 약어를 원래 낱말로 되돌려 광고인지 판단합니다.
- **고칠 수 있는 증거를 남깁니다.** 광고가 숨은 위치(CSS 선택자), 스크린샷, iframe 경로를 함께 기록합니다.
- **신고까지 이어집니다.** 신고 대상을 모으고, 알맞은 신고처를 추천하고, 위변조를 확인할 수 있는 증거 묶음(SHA-256)을 만들고, 접수 이력을 관리합니다.
- **설치와 인증이 필요 없습니다.** Windows 실행 파일 하나로 동작합니다. 사이트 소유 인증도, 외부 AI 서비스도 쓰지 않습니다.
- **정상적인 숨김은 제외합니다.** '본문 바로가기' 같은 접근성용 숨김과 단속 공지는 광고로 보지 않습니다.

## 검사 모드

- **빠른 검사**: 짧은 시간 안에 누리집 전체를 점검합니다.
- **안전 검사**: 운영 중인 누리집에 부담을 주지 않도록 속도와 검사 항목을 직접 정합니다.
